# 📘 Atividade: Jogo da Forca

## 🎯 Objetivo

Pratique o uso de strings, listas, condicionais e loops em Python criando um jogo em que o jogador tenta adivinhar uma palavra secreta.

## 📝 Tarefas

### 🛠️ Implementar o Jogo da Forca

#### Descrição
Crie um jogo da Forca que escolha uma palavra aleatoriamente e permita ao jogador adivinhar suas letras. Mostre o progresso da palavra a cada palpite e encerre a partida quando a palavra for descoberta ou as tentativas acabarem.

#### Requisitos
O programa concluído deve:

- Selecionar aleatoriamente uma palavra de uma lista predefinida.
- Aceitar palpites de letras e mostrar as letras descobertas e os espaços ainda ocultos (por exemplo, `_ _ _`).
- Controlar e exibir o número de tentativas incorretas restantes.
- Encerrar a partida quando o jogador adivinhar a palavra ou esgotar as tentativas.
- Exibir uma mensagem indicando se o jogador venceu ou perdeu.
